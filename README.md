# SpellPad Studio

A World of Warcraft addon: an in-game macro studio that bridges macro keypads (Stream Deck-style hardware and similar) to keybinds. Card-based macro manager, an on-screen button pad (the SpellPad), pages, profiles and context rules.

Targets WoW Forever (Interface 16001) and is being ported to retail.

## Install

Copy this folder to `World of Warcraft\_<client>_\Interface\AddOns\SpellPadStudio`, then start the game and type `/spellpad` (or `/sps`). A guided setup opens on the first login.
